# Self-improvement

How armada uses itself to build itself.

## The loop in one line

armada is built by armada: a fleet of role agents, generated by the same generator every user receives, implementing armada's own features and auditing its own code — proof the product works and the path by which it improves.

## Two modes

- **Patrol (audit)** — the fleet reviews armada's own repo, files findings against ledgers, and proposes fixes.
- **Voyage (feature)** — the fleet implements armada's next feature in an isolated `sandbox/<name>/` worktree lane, evidence-gated and PR-first.

## How it works

1. **Triage:** Requests run in-window for small fixes and ledger maintenance, or in a dedicated voyage lane for multi-file feature work.
2. **Execution:** Approved voyages scaffold a team, co-write the contract at `armada/REQUIREMENTS.md`, run evidence-gated phases, and finish PR-first — keeping `main` pristine.
3. **Audit:** Patrol audits feed the backlog and maintain quality across the codebase.
