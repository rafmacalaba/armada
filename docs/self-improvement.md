# Self-improvement

How armada uses itself to build itself. This is the restored overview doc; the two-mode
workflow details live in [armada-improves-armada.md](./armada-improves-armada.md), and the
triage decision (voyage vs. in-window) lives in [process/triage.md](./process/triage.md).

## The loop in one line

armada is built by armada: a fleet of role agents, generated by the same generator every
customer uses, implementing armada's own features and auditing its own code — proof the product
works, and the path by which it improves.

## Two modes

- **Patrol (audit)** — the fleet reviews armada's own repo, files findings.
- **Voyage (feature)** — the fleet implements armada's next feature in an isolated
  `sandbox/<name>/` worktree lane, evidence-gated and PR-first.

Validation results from real-repo runs are collected in [validation.md](./validation.md).
