# v1.2.1 Autonomous Voyage Trigger Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Commodore use autonomous reasoning for routine decisions while forcing clear net-new multi-file implementation through approved, automatically launched voyages.

**Architecture:** Keep policy in the generated orchestrator prompt and verify it through prompt regression tests. Keep existing CLI approval and voyage launch paths unchanged unless a failing regression identifies a concrete defect. Ship the prompt, tests, changelog, and version metadata together as `1.2.1`.

**Tech Stack:** Node.js >=22, ESM, `node:test`, npm package metadata, generated Markdown prompts.

## Global Constraints

- Net-new multi-file implementation is voyage work regardless of project size or low-risk classification.
- “Do it on your own” removes routine questions but does not bypass contract approval or safety gates.
- Approved contracts launch existing voyage flow automatically without a second voyage confirmation.
- Explicit in-window override does not grant main Commodore direct source-edit rights.
- QA remains active; risk controls staffing and evidence depth inside voyage.
- Full test suite must pass without ignored tests.
- Package, lockfile, CLI, and changelog must report release `1.2.1`.
