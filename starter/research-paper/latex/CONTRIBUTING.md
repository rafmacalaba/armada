## Pull request checklist

- [ ] `make` produces `main.pdf` without errors
- [ ] No undefined citations (`make` output)
- [ ] `references.bib` updated for any new `\cite`
- [ ] Description explains what and why

## Conventions

- One idea per section.
- Cite every claim.
