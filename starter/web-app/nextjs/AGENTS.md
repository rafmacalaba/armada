> Instructions for AI agents and humans working in this repository.

## Repository conventions

- TypeScript everywhere. Strict mode. No `any` without a written reason.
- Pure logic lives in `src/lib/` as exported functions — unit-testable, no JSX.
- Pages under `src/app/` stay thin; move logic into `src/lib/`.
- Tailwind utility classes, no bespoke CSS files unless required.
- No emojis in code, comments, print statements or logging.

## Workflow

1. Read the task/contract before touching code.
2. Write a failing test first (`src/lib/*.test.ts`), then implement.
3. Run `npm run test` — keep it green.
4. Run `npm run build` before claiming done.

## Quality bar

- Every pure function in `src/lib/` has a unit test.
- No console.log left in production code paths.
